# Deep Analysis

Each formal Deep Analysis receives a stable ID (`DA-NNN`) and a dedicated
directory once it becomes a durable research artifact.

A Deep Analysis directory should eventually preserve:
- objective and research questions
- primary sources
- paper / architecture analysis
- repository / implementation analysis
- training and data reconstruction
- Re-Aging suitability
- evidence classification
- Research Closeout
- resulting experiments / decisions

Historical chats are not automatically treated as migrated reports.
